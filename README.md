# AI 콘솔메이트

Behringer WING 콘솔 옆에서 함께 일하는 AI 음향 도우미입니다.

말로 요청하면 Claude(AI)가 콘솔을 대신 조작하거나 문제 해결 방법을 알려줍니다. 화면에서 직접 조절할 수도 있습니다.

- **왼쪽 화면 (흐름도):** 악기·마이크 소리가 어느 모니터, 메인 출력(MAIN·CENTER·YOUTUBE), 매트릭스(BABY·CAFE)로 얼마나 가는지 선으로 보여줍니다.
  - 상자를 누르면 그 연결만 보이고, 아래 슬라이더로 마우스나 키보드로 직접 조절할 수 있습니다.
  - 콘솔에서 바꾼 값도 2.5초마다 자동으로 반영됩니다. 자동 갱신에는 API 요금이 들지 않습니다.
- **오른쪽 화면 (대화):** "MONITOR에 KEY 좀 넣어줘"처럼 말로 요청하면 AI가 처리합니다.

## 예배 순서 버튼

화면 위쪽 "예배 순서" 줄에 찬양·설교·기도회 같은 버튼을 만들어 두고, 한 번에 콘솔을 전환합니다.

1. 콘솔을 그 순서에 맞게 맞춘 뒤 **＋ 지금 상태 저장** → 이름 입력 → 저장.
   - 기본으로 **채널 뮤트와 페이더**만 담습니다. 모니터 센드는 예배 중 맞춘 모니터를 덮어쓸 수 있어 필요할 때만 체크하세요.
   - MAIN(예배당) 뮤트는 안전을 위해 담지 않습니다.
2. 예배 중에는 버튼(또는 **Alt+숫자**)을 누르면 바뀔 내용이 먼저 나옵니다. **전환하기**를 누르면 적용되고, 페이더는 1초 동안 부드럽게 움직입니다.
3. 잘못 눌렀으면 **↶ 되돌리기**로 바로 전 상태로 돌아갑니다.
4. 버튼 옆 **⋯**: 이름 바꾸기, 지금 상태로 다시 저장, 순서 이동, 삭제.
5. AI에게 말로도 됩니다: "지금 상태를 설교로 저장해줘", "설교로 바꾸면 뭐가 바뀌어?", "설교로 바꿔줘".

버튼은 이 프로그램 폴더의 `scenes.json`에 저장됩니다(콘솔의 스냅샷과는 별개).

## 다른 교회에 나눠 주기

1. 이 폴더의 **`make_dist.bat`**을 더블클릭하면 `dist\AI콘솔메이트_날짜.zip`이 만들어집니다.
   - 우리 교회의 API 키, 예배 순서 버튼, 스피커 이름표, 교회 메모는 **들어가지 않습니다**.
2. 받는 교회에서는 압축을 풀고 **`install.bat`**을 더블클릭합니다. Python 설치부터 바탕화면 아이콘까지 자동으로 해 줍니다.
3. 처음 켜면 **처음 설정 마법사**가 열립니다: 콘솔 찾기 → 교회 이름·메모 → API 키(선택) → 완료.
4. 설정은 언제든 오른쪽 위 **⚙ 설정**에서 바꿀 수 있습니다.
   - **교회 정보:** 교회 이름과 **음향 메모**(예: "A 버스 = 드럼 모니터"). AI가 항상 참고합니다.
   - **콘솔 연결:** 자동 찾기 또는 IP 직접 입력.
   - **설명서:** AI가 참고할 콘솔 설명서 요약을 고릅니다. 기본은 내장된 WING 공식 설명서 요약입니다. (아래 '설명서 넣기' 참고)
   - **API 키**
   - **백업·옮기기:** 교회 설정(이름·메모·예배 순서·스피커 이름표·설명서 요약)을 파일로 내보내거나 가져옵니다. PC를 바꿀 때 씁니다.

## 설명서 넣기 (다른 기종·새 판)

⚙ 설정 → **📖 설명서** 탭에서 콘솔 모델 이름을 넣고 둘 중 하나를 고릅니다. 둘 다 API 키가 필요합니다.

- **방법 1. 인터넷에서 찾기:** AI가 공식 설명서 PDF를 찾아 후보를 보여 줍니다(공식/사본 표시). **이 파일 받기**를 누르면 프로그램이 받아 읽습니다. 사이트가 막혀 있으면 **열어 보기**로 직접 내려받아 방법 2로 올리세요.
- **방법 2. 파일 올리기:** 내려받아 둔 설명서 PDF(또는 txt)를 올립니다. 80 MB까지 가능합니다.

파일을 읽으면 **예상 요금**(설명서 한 권에 보통 1천~3천 원)을 먼저 보여 줍니다. **AI 참고 자료 만들기**를 누르면 2~5분 뒤 봉사자용 요약(쪽 번호 포함)이 만들어지고, AI가 바로 그 자료를 참고합니다.
- 설명서에 없는 내용은 "(설명서에서 확인 못 함)"으로 표시됩니다.
- 만든 요약은 `manuals` 폴더에 저장되고, **보기**로 내용을 확인하거나 **이걸로 쓰기**로 바꿀 수 있습니다.
- WING이 아닌 기종(X32 등)의 설명서를 쓰면 AI가 사용법은 그 기종에 맞게 안내합니다. 다만 화면과 AI의 직접 조작은 아직 WING 계열에서만 됩니다.

## 지원 콘솔

| 기종 | 볼륨·뮤트·모니터·메인 | 채널 설정(게인·48V·로우컷·EQ·컴프) | 예배 순서 | 라우팅 | 이펙트 |
|---|---|---|---|---|---|
| Behringer WING / Compact / Rack | 됨 | 됨 | 됨 | 보기·바꾸기 | 보기·조절 |
| Behringer X32 (Compact·Producer·Rack·Core) / Midas M32 | 됨 | 됨 (EQ 1~4밴드, 로우컷=HPF) | 됨 | 입력 보기만 | 아직 안 됨 |

- 콘솔 찾기에서 WING과 X32/M32를 함께 찾아 자동으로 구별합니다. IP를 직접 넣어도 기종을 알아냅니다.
- X32/M32에서는 메인 1 = MAIN LR, 메인 2 = MONO(CENTER), 매트릭스 6개, DCA 8개입니다. 채널 → MAIN LR은 켜기/끄기만 있고 크기는 채널 페이더입니다.
- X32/M32 지원은 공개 프로토콜 문서(Patrick-Gilles Maillot, *Unofficial X32/M32 OSC Remote Protocol*)와 가짜 X32(`x32_simulator.py`)로 시험했습니다. **실제 X32/M32에서는 아직 확인하지 않았으니**, 처음 쓸 때는 예배가 없는 시간에 페이더·뮤트부터 확인해 주세요.
- X32/M32 사용법 안내를 정확하게 하려면 ⚙ 설정 → 📖 설명서에서 X32 설명서를 넣어 주세요.
- 다른 회사 콘솔(Yamaha, Allen & Heath 등)은 아직 지원하지 않습니다. 설명서를 넣으면 AI가 사용법은 안내할 수 있습니다.

## 볼륨·채널 설정·라우팅

- **MAIN·CENTER·YOUTUBE·모니터의 전체 볼륨:** 흐름도에서 그 상자를 누르면 맨 위 노란 줄 **"전체 볼륨"** 슬라이더와 뮤트 버튼이 나옵니다. (MAIN 뮤트는 확인을 받습니다.) 그 아래는 악기별로 그 출력에 들어가는 크기입니다.
- **채널 설정:** 악기를 누르면 게인·+48V·필터·EQ·컴프·인서트가 나옵니다(콘솔 HOME 화면과 같음).
- **이펙트:** 위쪽 탭 **이펙트**에서 16칸의 종류·연결 위치·섞는 양.
- **라우팅 보기:** 흐름도 왼쪽 이름 앞에 입력 단자(A16 등), 오른쪽 상자에 🔌 출력 단자가 표시됩니다.
- **스피커 이름표:** 라우팅 탭 도식의 맨 오른쪽 **🔊 스피커** 칸을 눌러 출력 단자마다 실제 스피커 이름(예: A3 = 드럼 바닥 모니터)을 붙입니다. 콘솔은 바뀌지 않고 이 컴퓨터의 `speakers.json`에만 저장되며, 흐름도 상자에도 그 이름이 표시됩니다. 흐린 이름은 이름표가 없어 추측한 것입니다.
- **라우팅 바꾸기:** 채널 설정의 **입력 단자 바꾸기**, 출력 상자의 **출력 단자 바꾸기**.
  - 항상 "바뀔 내용 보기"로 무엇이 바뀌고 무엇이 덮어써지는지 먼저 보여 주고, **확인 — 바꾸기**를 눌러야 적용됩니다.
  - 적용 후 콘솔에서 다시 읽어 확인하고, 다르면 자동으로 원래대로 돌립니다.
  - **↶ 라우팅 되돌리기**로 가장 최근 변경을 취소할 수 있습니다.
  - 예배 중에는 라우팅을 바꾸지 마세요. 소리가 통째로 끊길 수 있습니다.

## 처음 한 번만 할 일

1. **Claude API 키 발급**
   - https://console.anthropic.com 에 가입하고 결제 수단을 등록한 뒤 **API Keys**에서 키를 만듭니다.
   - 사용한 만큼 요금이 나옵니다. 질문 한 번에 보통 몇십 원 수준입니다. 콘솔의 **Limits**에서 월 사용 한도를 정해 두는 것을 권장합니다.
2. 프로그램 화면 오른쪽 위 **⚙ 설정**(또는 "AI" 상태 표시)을 눌러 키를 붙여 넣고 **확인하고 저장**을 누릅니다.
   - 키가 맞는지 바로 확인하고(요금 없음), 다시 켤 필요 없이 바로 AI 대화를 쓸 수 있습니다.
   - 키는 이 컴퓨터의 `config.json`에만 저장됩니다. 다른 사람과 공유하지 마세요.
   - 키 변경은 프로그램이 켜진 컴퓨터에서만 할 수 있습니다(태블릿 등 다른 기기에서는 불가).
3. `wing_ip`는 `""`(비워 둠)이 기본입니다. 비워 두면 콘솔을 자동으로 찾기 때문에, 공유기가 콘솔 IP를 바꿔도 그대로 동작합니다.
4. 콘솔에서 **SETUP → Remote**로 들어가 OSC가 허용되어 있고 Remote Lock이 꺼져 있는지 확인합니다.

## 실행

- **바탕화면의 "AI 콘솔메이트" 아이콘**(또는 `실행.bat`)을 더블클릭하면 브라우저에 화면이 열립니다(http://localhost:8800).
  - 작업 표시줄에 작은 검은 창이 함께 뜹니다. 이 창을 닫으면 프로그램이 꺼집니다.
  - 이미 켜져 있을 때 아이콘을 다시 누르면 화면만 다시 열립니다.
- 콘솔 없이 연습하려면 `config.json`의 `wing_ip`를 `"127.0.0.1"`로 바꾸고 **`테스트(콘솔없이).bat`**을 실행하세요. 가짜 콘솔로 동작합니다.

## 안전장치

- 한 번에 10 dB 넘게 올리면 확인을 받습니다. 화면에서는 확인 창이 뜨고, AI는 먼저 사용자에게 묻습니다.
- 메인 스피커 뮤트는 AI가 반드시 확인을 받은 뒤에만 합니다.
- 기본 설정에서는 이 컴퓨터에서만 접속할 수 있습니다. 태블릿 등 다른 기기에서도 쓰려면 `allow_other_devices`를 `true`로 바꾸세요. 단, 같은 와이파이에 연결된 사람은 누구나 조작할 수 있게 됩니다.

## API 키가 없을 때

키를 넣지 않고 실행하면 **보기 전용**으로 열립니다. 흐름도와 직접 조절은 쓸 수 있고, 대화창만 꺼집니다.

## (참고) 구독으로 쓰는 방법

`wing_mcp.py`는 같은 조작 기능을 Claude 데스크톱 앱에 연결하는 파일입니다(MCP 서버). 지금은 Claude 앱에 등록되어 있지 않습니다. 나중에 API 대신 구독으로 쓰고 싶으면 이 파일을 Claude 앱에 등록하면 됩니다. 이때 `pip install "mcp<2"`가 필요합니다.

## 아직 안 되는 것

- 콘솔 자체의 씬(스냅샷) 불러오기 — 대신 '예배 순서' 버튼을 쓰세요.
- X32/M32의 라우팅 바꾸기와 이펙트 조절.
- WING·X32/M32 외의 콘솔 조작.

이런 요청을 하면 AI가 콘솔에서 직접 하는 방법을 안내합니다.

## 참고 자료

WING과 통신하는 방법(OSC 주소, 값 형식)은 Patrick-Gilles Maillot의 *WING Remote Protocols* 문서와 공개 프로젝트 [behringer-wing-mcp](https://github.com/ralfferreira/behringer-wing-mcp)를 참고했습니다. 실제 콘솔에서 값을 읽어 맞는지 확인했습니다.

# 🎚 AI 콘솔메이트

**교회 음향 봉사자를 위한 AI 콘솔 도우미**입니다. 디지털 음향 콘솔 옆에서 함께 일해요.

> "드럼 모니터에 베이스 조금 더 넣어 줘"
> "설교 때 목사님 마이크가 작아요"
> "하울링이 나요, 어떻게 해요?"

말로 부탁하면 AI가 콘솔을 대신 조작하거나 해결 방법을 차근차근 알려 줍니다. 소리가 어디로 가는지는 화면에 그림으로 보여 줍니다.

지원 콘솔: **Behringer WING** 계열 · **Behringer X32 / Midas M32** 계열 ([자세히](#-지원-콘솔))

---

## ✨ 이런 걸 할 수 있어요

| | |
|---|---|
| 🗺 **소리 흐름도** | 악기·마이크 소리가 어느 스피커·모니터로 얼마나 가는지 선으로 보여 줘요. 콘솔에서 바꾼 값도 자동으로 따라와요. |
| 💬 **말로 조작** | "보컬 모니터에 피아노 조금", "설교 마이크 로우컷 켜 줘"처럼 말하면 AI가 처리하고 무엇을 바꿨는지 알려 줘요. |
| 🎛 **화면에서 직접 조절** | 마우스·키보드로 볼륨, 뮤트, 게인, +48V, EQ, 컴프를 조절해요. |
| ⛪ **예배 순서 버튼** | 찬양·설교·기도회 상태를 저장해 두고 버튼 하나로 바꿔요. 잘못 누르면 되돌리기. |
| 🔌 **라우팅·스피커 이름표** | 어느 단자가 어느 채널·스피커와 이어지는지 그림으로 보여 주고, "A3 = 드럼 바닥 모니터"처럼 이름을 붙여요. |
| 📖 **설명서 지식** | 콘솔 공식 설명서를 바탕으로 사용법을 쪽 번호와 함께 안내해요. 다른 기종 설명서도 넣을 수 있어요. |
| 🚦 **연결 상태 알림** | 콘솔 연결이 끊기거나 메인이 뮤트되면 화면 위에 바로 알려 줘요. |

## 🧰 준비물

- **Windows PC** (Windows 10 / 11). 방송실 노트북이면 충분해요.
- **콘솔과 같은 공유기(네트워크)에 연결된 PC**. 콘솔 뒷면 랜 단자를 공유기에 연결하세요.
- **(선택) Claude API 키**. AI 대화에만 필요해요. 키가 없어도 흐름도와 직접 조절은 쓸 수 있어요. → [API 키 만들기](#-claude-api-키-만들기-선택)

## 📥 설치 (5분)

1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼 → **Download ZIP**을 누르세요.
2. 받은 파일을 **압축 풀기** 하세요. 예를 들어 `문서` 폴더에 풀면 돼요.
3. 풀린 폴더에서 **`install.bat`** 을 더블클릭하세요.
   - Python(무료)이 없으면 자동으로 설치해요. 중간에 허락을 물으면 **예**를 누르세요.
   - 바탕화면에 **AI 콘솔메이트** 아이콘이 생기고, 브라우저에 화면이 열려요.

> 💡 Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요. 인터넷에서 받은 파일이라 한 번 확인하는 것이에요.

다음부터는 **바탕화면의 AI 콘솔메이트 아이콘**만 누르면 돼요.

## 🪄 처음 설정 (2~3분)

처음 켜면 **설정 마법사**가 열려요.

1. **콘솔 찾기**: 같은 네트워크의 콘솔을 자동으로 찾아요. 우리 교회 콘솔을 고르세요.
2. **교회 정보**: 교회 이름과 **음향 메모**를 적어요. AI가 늘 이 메모를 참고해요.
   ```
   - 버스 3 = 드럼 모니터, 버스 5 = 보컬 인이어
   - 메인 2(CENTER) = 자모실, 메인 3(YOUTUBE) = 방송
   - 설교 때는 목사님 핀마이크(채널 12)만 켜기
   ```
3. **AI 키**: 있으면 붙여 넣고, 없으면 건너뛰어도 돼요.
4. **완료!**

설정은 언제든 화면 오른쪽 위 **⚙ 설정**에서 바꿀 수 있어요.

> ⚠ 콘솔에서 **SETUP → REMOTE** 화면의 **REMOTE LOCK(원격 잠금)** 이 꺼져 있어야 조작할 수 있어요.

## 🔑 Claude API 키 만들기 (선택)

AI 대화는 Anthropic의 Claude를 써요. 쓴 만큼 요금이 나오는 방식이에요.

1. https://console.anthropic.com 에 가입하고 결제 수단을 등록하세요.
2. **API Keys → Create Key**로 키(`sk-ant-`로 시작)를 만들어 복사하세요.
3. 프로그램의 **⚙ 설정 → 🔑 API 키**에 붙여 넣고 **확인하고 저장**을 누르세요. 바로 쓸 수 있어요.

**요금은 얼마나 나오나요?**
- 질문 한 번에 보통 **몇십 원**이에요.
- 화면 자동 갱신, 직접 조절, 예배 순서 버튼에는 요금이 **들지 않아요**. AI에게 말을 걸 때만 들어요.
- 설명서 요약을 새로 만들 때는 한 권에 1천~3천 원 정도예요. 미리 예상 요금을 보여 줘요.
- 걱정되면 console.anthropic.com의 **Limits**에서 월 사용 한도를 정해 두세요.

> 🔒 키는 이 PC의 `config.json`에만 저장되고, GitHub나 백업 파일에는 들어가지 않아요. 다른 사람과 공유하지 마세요.

## 🙋 사용법

### 화면 둘러보기
- **왼쪽, 흐름도**: 왼쪽은 악기·마이크, 오른쪽은 메인·모니터·매트릭스예요. 선이 굵을수록 크게 들려요. 점선은 뮤트된 연결이에요.
  - 상자를 누르면 그 연결만 보이고, 아래 슬라이더로 조절할 수 있어요.
  - 메인·모니터 상자를 누르면 맨 위 **"전체 볼륨"** 줄에서 그 출력 전체를 조절해요.
  - 악기 이름을 누르면 게인·+48V·로우컷·EQ·컴프 같은 **채널 설정**이 나와요.
- **위쪽 탭**: 흐름도 · 카드 · 이펙트 · 라우팅
- **오른쪽, AI 대화**: 말로 부탁하세요.

### AI에게 이렇게 말해 보세요
- "지금 드럼 모니터에 뭐가 들어가 있어?"
- "보컬 1 마이크 소리가 먹먹해요"
- "YOUTUBE 방송에 피아노가 너무 작대"
- "새 무선마이크를 채널 20에 꽂았어. 어떻게 해?"
- "콘솔에서 SOF는 어떻게 써?"

### ⛪ 예배 순서 버튼
1. 콘솔을 그 순서에 맞게 맞춘 뒤 **＋ 지금 상태 저장** → 이름(예: 설교) → **저장** (Enter도 돼요).
   - 기본으로 **채널 뮤트와 페이더**만 담아요. 모니터는 필요할 때만 체크하세요.
   - 안전을 위해 메인(예배당) 뮤트는 담지 않아요.
2. 예배 중 버튼(또는 **Alt+숫자**)을 누르면 바뀔 내용을 먼저 보여 줘요. **전환하기**를 누르면 페이더가 1초 동안 부드럽게 움직여요.
3. 잘못 눌렀으면 **↶ 되돌리기**.

### 🔌 라우팅과 스피커 이름표 (WING)
- **라우팅** 탭에서 입력 단자 → 채널 → 메인·모니터 → 출력 단자 → 스피커 흐름을 한눈에 봐요.
- 맨 오른쪽 **🔊 스피커** 칸을 눌러 실제 스피커 이름을 붙이세요. 콘솔은 바뀌지 않아요.
- 단자를 바꿀 때는 항상 **바뀔 내용을 먼저 보여 주고**, 확인을 눌러야 적용돼요. 적용 후 콘솔에서 다시 읽어 확인하고, **↶ 라우팅 되돌리기**로 취소할 수 있어요.
- ⚠ 예배 중에는 라우팅을 바꾸지 마세요. 소리가 통째로 끊길 수 있어요.

### 📖 설명서 넣기 (다른 기종·새 판)
**⚙ 설정 → 📖 설명서**에서 모델 이름(예: Behringer X32)을 넣고 고르세요.
- **인터넷에서 찾기**: AI가 공식 설명서 PDF를 찾아 줘요. 공식 파일과 사본을 구분해 보여 줘요.
- **파일 올리기**: 내려받아 둔 PDF를 올려요(80 MB까지).

몇 분 뒤 쪽 번호가 붙은 봉사자용 요약이 만들어지고, AI가 바로 그 자료를 참고해요. 설명서에 없는 내용은 "(설명서에서 확인 못 함)"으로 표시돼요.

### 💾 백업·PC 옮기기
**⚙ 설정 → 💾 백업·옮기기**에서 교회 설정을 파일 하나로 내보내고 새 PC에서 가져와요. 교회 이름·메모, 예배 순서, 스피커 이름표, 설명서 요약이 들어가요. API 키는 빠져요.

| 기종 | 볼륨·뮤트·모니터·메인 | 채널 설정 | 예배 순서 | 라우팅 | 이펙트 |
|---|:-:|:-:|:-:|:-:|:-:|
| **Behringer WING / WING Compact / WING Rack** | ✅ | ✅ | ✅ | 보기·바꾸기 | 보기·조절 |
| **Behringer X32** (Compact·Producer·Rack·Core) / **Midas M32** | ✅ | ✅ | ✅ | 입력 보기만 | ❌ |

- 콘솔 찾기에서 기종을 자동으로 구별해요.
- **X32/M32**:
  - 메인 1 = MAIN LR, 메인 2 = MONO(CENTER)예요.
  - EQ는 1~4번 밴드, 로우컷은 HPF예요.
  - 공개 프로토콜 문서와 가짜 X32로 시험했어요. **실제 X32/M32로는 아직 확인하지 않았으니**, 처음에는 예배가 없는 시간에 페이더·뮤트부터 확인해 주세요. 써 보신 결과를 [Issues](../../issues)에 알려 주시면 큰 도움이 돼요!
- Yamaha, Allen & Heath 같은 다른 회사 콘솔은 아직 조작하지 못해요. 설명서를 넣으면 사용법 안내는 할 수 있어요.

## ❓ 자주 묻는 질문

<details>
<summary><b>콘솔을 못 찾아요</b></summary>

1. 콘솔 전원과 뒷면 랜선(공유기 연결)을 확인하세요.
2. PC가 **같은 공유기**에 연결되어 있는지 확인하세요. 교회 와이파이가 여러 개면 특히 확인이 필요해요.
3. 콘솔 **SETUP → REMOTE**에서 원격 잠금이 꺼져 있는지 확인하세요.
4. 그래도 안 되면 콘솔 SETUP → NETWORK에 나오는 IP를 **⚙ 설정 → 🎚 콘솔 연결**에 직접 넣으세요.
</details>

<details>
<summary><b>프로그램을 끄려면?</b></summary>

작업 표시줄의 **검은 창(AI ConsoleMate)** 을 닫으면 꺼져요. 브라우저 창만 닫으면 프로그램은 계속 켜져 있어요. 아이콘을 다시 누르면 화면만 다시 열려요.
</details>

<details>
<summary><b>태블릿이나 휴대폰에서도 볼 수 있나요?</b></summary>

`config.json`의 `"allow_other_devices"`를 `true`로 바꾸고 프로그램을 다시 켜세요. 그런 다음 태블릿 브라우저에서 `http://PC의IP:8800` 으로 들어가면 돼요.

⚠ 단, 같은 와이파이에 연결된 사람은 누구나 조작할 수 있게 돼요. API 키와 설정 변경은 PC에서만 할 수 있어요.
</details>

<details>
<summary><b>콘솔 없이 연습해 볼 수 있나요?</b></summary>

`테스트(콘솔없이).bat`을 실행하면 **가짜 WING 콘솔**이 함께 켜져요. 그다음 **⚙ 설정 → 🎚 콘솔 연결**에서 "연습용 가짜 콘솔"을 고르세요. 실제 콘솔은 전혀 바뀌지 않아요.
</details>

<details>
<summary><b>새 버전으로 업데이트하려면?</b></summary>

새 ZIP을 받아 **같은 폴더에 덮어쓰기**로 풀면 돼요. 교회 설정(`config.json`, `scenes.json`, `speakers.json`, `manuals` 폴더)은 ZIP에 들어 있지 않아서 그대로 남아요. 걱정되면 먼저 **💾 백업**을 해 두세요.
</details>

<details>
<summary><b>API 키 없이 쓸 수 있나요?</b></summary>

네. 흐름도, 직접 조절, 예배 순서, 라우팅 보기는 모두 돼요. AI 대화창만 꺼져요.
</details>

## 🧑‍💻 개발·참여하시는 분께

- Python 3.10 이상, 표준 라이브러리와 `anthropic`, `pypdf` 패키지를 써요. 웹 화면은 `index.html` 파일 하나로 되어 있어요.
- 실행: `pip install -r requirements.txt` → `python app.py` → http://localhost:8800
- 가짜 콘솔: `python wing_simulator.py` (WING, UDP 2223) · `python x32_simulator.py` (X32, UDP 10023)
- 시험용 환경변수: `CONSOLEMATE_CONFIG`, `CONSOLEMATE_SCENES`, `CONSOLEMATE_SPEAKERS`, `CONSOLEMATE_MANUALS`를 쓰면 실제 설정을 건드리지 않고 시험할 수 있어요.
- 배포용 ZIP: `make_dist.bat` → `dist\AI콘솔메이트_날짜.zip`. 교회 정보는 자동으로 빠져요.

| 파일 | 역할 |
|---|---|
| `app.py` | 웹 서버, AI 대화, 연결 상태 점검 |
| `wing_tools.py` | 조작 기능(센드·페이더·뮤트·채널 설정·라우팅·이펙트·예배 순서)과 AI 도구 정의 |
| `wing_osc.py` / `x32_osc.py` | WING(UDP 2223) / X32·M32(UDP 10023)와 OSC 통신. X32는 WING 방식 주소를 X32 주소로 바꿔 줘요 |
| `consoles.py` | 콘솔 찾기·기종 구별 |
| `manuals.py` · `wing_knowledge.md` | 설명서 → AI 참고 자료 / 내장된 WING 설명서 요약 |
| `scenes.py` · `speakers.py` | 예배 순서 버튼 · 스피커 이름표 저장 |
| `index.html` | 화면 |
| `wing_mcp.py` | (선택) Claude 데스크톱 앱 연결용 MCP 서버 |
| `install.bat` · `start.bat` | 설치 · 실행 |

**참고 자료**: Patrick-Gilles Maillot의 *WING Remote Protocols*와 *Unofficial X32/M32 OSC Remote Protocol*, 공개 프로젝트 [behringer-wing-mcp](https://github.com/ralfferreira/behringer-wing-mcp)를 참고했어요.

버그 제보와 제안은 [Issues](../../issues)에 남겨 주세요. 다른 교회에서 써 본 경험이 가장 큰 도움이 돼요. 🙏
